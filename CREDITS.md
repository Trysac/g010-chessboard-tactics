# Credits

Everything in this repository is original work made for this project; no third-party
assets are included.

| Asset | Where | How it was made |
|---|---|---|
| Chess pieces, board, rocks, highlights | `Assets/Scripts/Game` | Built at run time from Unity's primitive meshes (`PieceModel.cs`, `BoardView.cs`) |
| Materials, particle texture, unit data, scene, app icon | `Assets/Art`, `Assets/Data`, `Assets/Scenes` | Generated by `Assets/Editor/ProjectBuilder.cs` |
| Music (battle theme, camp theme) and sound effects | `Assets/Audio` | Synthesized by `tools/audio` (Python standard library, encoded with ffmpeg) |
| Font | — | Unity's default runtime font |

## Removed third-party content

Earlier versions of this repository (before the `fix/asset-licensing` changes) contained three
music files in `Assets/MusicAndSounds`: "A New Adventure - Fantasy Music Mix", "DRUMANIA - Epic
Powerful Drum Music Mix" and "Epic Music Mix - Drums And Percussion". They are compilation mixes
whose author and licence were not recorded, so they were removed and replaced with original
synthesized music. They remain in the git history, which was not rewritten. The TextMesh Pro
essential resources that shipped with Unity were removed when the UI moved to UI Toolkit.
